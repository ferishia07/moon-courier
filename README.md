# Moon Courier

Pilot a little astronaut around a lunar outpost. Dodge patrol drones, collect every orange cargo crate, and return to the ship before your suit runs out of health.

Open `index.html` in a browser and select **Start mission**. Move with **WASD**, the **arrow keys**, or the on-screen direction buttons. Deliver the cargo to unlock a new sector with a randomized crate layout. There is no sector limit.

Built with HTML, CSS, JavaScript, and Canvas. Plays offline without dependencies.
